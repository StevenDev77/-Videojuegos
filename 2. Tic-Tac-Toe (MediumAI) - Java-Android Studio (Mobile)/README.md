# Tic-Tac-Toe — Java / Android Studio (MediumAI)

Proyecto Android nativo en Java, migrado de `ControlWeakIntelligentMoves`. Jugador X, IA 0. La IA mantiene la lógica heurística original: prioriza centro, luego HeuristicNumericalMethod con sumas 6 y 2, y aleatorio.

## Abrir y ejecutar

Abre esta carpeta en Android Studio, espera sincronización Gradle y ejecuta en emulador o dispositivo Android (API 23+). Requiere JDK 17 y Android SDK 35.
