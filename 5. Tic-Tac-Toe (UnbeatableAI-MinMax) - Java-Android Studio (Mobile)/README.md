# Tic-Tac-Toe — Java / Android Studio

Proyecto Android nativo en Java, migrado del juego WinForms. El jugador usa X y la IA usa O; la IA elige sus movimientos con MinMax y no puede perder frente a un juego correcto.

## Abrir y ejecutar

Abre esta carpeta en Android Studio, espera la sincronización de Gradle y ejecuta la app en un emulador o dispositivo Android (API 23 o superior). Requiere Android Studio con JDK 17 y Android SDK 35.
