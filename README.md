# -Videojuegos

Proyectos de Tic-Tac-Toe migrados de Java Swing a Android Studio.

## Estructura

- `1. Tic-Tac-Toe (MediumAI) - Java-Android Studio (Mobile)` — IA heurística MediumAI en Java
- `2. Tic-Tac-Toe (MediumAI) - Kotlin-Android Studio (Mobile)` — IA heurística MediumAI en Kotlin
- `5. Tic-Tac-Toe (UnbeatableAI-MinMax) - Java-Android Studio (Mobile)` — IA invencible con MinMax en Java
- `6. Tic-Tac-Toe (UnbeatableAI-MinMax) - Kotlin-Android Studio (Mobile)` — IA invencible con MinMax en Kotlin

## Requisitos

- Android Studio, JDK 17
- Android SDK 35
- API 23 o superior

## Uso

1. Abre la carpeta del proyecto en Android Studio
2. Espera sincronización de Gradle
3. Ejecuta en emulador o dispositivo Android

## Notas

- Los APKs no están versionados (están en `.gitignore`). Se generan con `./gradlew assembleDebug` dentro de cada proyecto.
